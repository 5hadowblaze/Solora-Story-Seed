# Demo script (aim: 65–75 seconds)

Use only fictional workshop content.

1. **0–10s:** Show the Story Seed home screen. “Small experiences disappear before we can use them. Solora saves them as lore.”
2. **10–35s:** Tap Save a moment. Enter a short title, situation, action, result and learning. “I keep the facts in my own words.”
3. **35–48s:** Tap Shape my story. Show the editable draft. “It arranges my words without inventing achievements.”
4. **48–65s:** Save, show the orb in Lore, open it and tap Share story text. “One moment becomes a reusable story.”
5. **65–75s:** “Codex built and tested this journey today, including a cross-platform build fix. The earlier Solora idea is credited; this entry’s code was created during the hackathon.”
